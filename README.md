# ⏱️ Stopwatch Timer

A simple and responsive Stopwatch Timer built using HTML, CSS, and JavaScript.

## 🚀 Features

- ▶️ Start the stopwatch
- ⏸️ Stop the stopwatch
- 💾 Store lap times
- 🗑️ Clear the stopwatch
- 📋 Store up to 5 lap times
- 📱 Responsive design
- 🎨 Digital stopwatch-style UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- setInterval()
- Event Listeners
